# 扩展包合集（官方）

这里放作者审核过的扩展包（`.json` 文件）。每次构建（`npm run build:desktop` 或 `npm run build:dev`）时，这个文件夹里的所有 `.json` 都会自动打包进软件：

- 软件里「题库扩展包」面板最上面会出现 **官方合集**，同学点「预览并安装」就能一键并入题库，不用再传文件；
- 装好的包会显示绿色的 **官方审核** 标签。

## 「官方审核」是怎么判断的

软件会给扩展包的内容算一个“指纹”（组名、药名、机制、适应证、不良反应、区分要点……逐字参与计算）。只有和软件里打包的官方版本**一字不差**，才显示「官方审核」：

- 同学之间直接传这个 JSON 文件，导入后也会显示官方审核（内容没变）；
- 文件被人改过一个字，就对不上，导入时会提醒“和官方版本不一致，可能被改过”，也不会显示官方；
- 装好之后自己在编辑器里改过内容，官方标记会自动去掉。

## 怎么把一个包收进合集

1. 同学把写好的扩展包 JSON 发给你（写法见项目根目录的「扩展包写法说明.md」）。
2. 在软件里导入预览，逐条核对；可以点「AI 自查」让 AI 帮忙挑错，再对照讲义改好。
3. 核对完，在「导入 / 管理」里点这个包的「导出」，把导出的 JSON 放进这个文件夹（文件名随意，建议用包名）。
4. 运行 `npm run build:desktop` 发布新版本。新版本里就带上了这个包。

> 合集里的包会随软件一起分发，内容准确性请认真核对；考试以讲义为准。不要放直接照抄教材、讲义大段原文的内容。

# 药理闯关

按“药物组”闯关的口腔药理学记忆游戏：186 种药、53 个记忆单元。
玩法有查房问答、药柜分拣、连线配对（含三合一）、病例诊室、中英默写、同类药物辨析、错题专练、AI 出题；
自带合成背景音乐、中英双语、错题本 / 掌握度热力图、完整备份恢复。

作者：红烧肉大王TCA

每次发布改了什么，见 [更新日志.md](更新日志.md)。

扩展包怎么写，见 [扩展包写法说明.md](扩展包写法说明.md)；作者审核过的官方扩展包放在 [扩展包合集/](扩展包合集/README.md)，构建时自动打包进软件。

## 快速开始

需要先装 [Node.js](https://nodejs.org)（18 以上）。第一次在项目文件夹里运行：

```bash
npm install
```

常用命令：

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地预览，浏览器打开 http://localhost:5181/ ，改完代码刷新即可 |
| `npm run build` | 生成成品到 `dist/`：在线版（`index.html` + `app.js` + `app.css`）和离线单文件版（`dist/offline/药理闯关-离线版.html`），外加不含摇滚医生的精简版（`药理闯关-离线版-精简.html`，约 1.1 MB） |
| `npm run build:desktop` | 构建，并把离线版和精简版都复制到桌面 |
| `npm test` | 构建并跑全部自动测试 |
| `npm run build:dev` | 开发者版：桌面上的 `药理闯关-开发者版.html`，快捷方式「药理闯关（开发者版）」打开。左下角 DEV 面板有作弊开关（选择题 / 连线怎么答都对）、成就逐个解锁、闪卡、连击档位跳转、特效预览。数据加了 `dev~` 前缀、快捷方式还用独立的 Edge 配置，和正式版互不影响；正式版构建时作弊代码整段删掉（`core/dev.js` 的 `__DEV__`） |

> 源码用的是 ES 模块，**不能直接双击 `src/index.html` 打开**（浏览器不允许本地文件加载多个模块），要用 `npm run dev`。
> 给手机 / 平板用的是构建出来的离线单文件版，双击就能打开，和以前一样。

## 目录结构

```
src/
├─ index.html          页面骨架（顶栏、主区域）
├─ main.js             入口：导入顺序就是执行顺序
├─ styles/             样式，按页面分文件，index.css 决定先后；combo.css 是连击 / 连线特效，achieve.css 是成就与闪卡
├─ core/               基础：工具函数、本地存储、设置与学习状态、返回键、共享注册表
├─ data/               题库数据：drugs（药物与分组）、facts（单药考点）、classes（同类辨析）、cases（病例）、pairs（易混药对）
│                      index.js 把原始数据整理成查找表
├─ engine/             出题引擎：各题型怎么出、干扰项怎么选、解析卡片
├─ records/            学习记录：错题本、报错清单、轮换记录、备份与导入导出
├─ games/              各玩法：quiz、sort、match、case、spell、classes、topic、drills
├─ pages/              页面：首页、选择范围、结算、图鉴、热力图、题库总览、设置
├─ ui/                 界面组件：切页与提示、特效（combo.js 连击节奏，linkfx.js 连线走线与流光）、背景、心电图、吉祥物、省电、触屏处理、顶栏
├─ music/              音乐：engine（音频引擎）→ instruments（乐器音色）→ compose（乐谱解析与编曲）
│                      → scores/（每首歌一个文件）→ tracks（曲目表）→ player（播放模式）
├─ ai/                 AI 出题
└─ i18n/               中英文：data（题库英文）、ui（界面英文）、i18n（切换逻辑）
tools/                 构建（build.mjs，顺带把「扩展包合集/」打包进 src/data/catalog.js）和本地预览（dev.mjs）
tests/                 自动测试
legacy/                拆分前的单文件版和历史脚本，只作参考
```

## 写代码的约定

- **模块顺序**：`src/main.js` 里的 import 顺序就是加载顺序。一个模块只 `import` 排在它前面的模块，这样永远不会循环依赖。
- **共享注册表 `PG`**（`core/registry.js`）：
  - 要调用**排在后面**的模块里的函数（比如游戏结束回首页），写 `PG.home()`，不要 import；
  - 要给**别的模块的变量**重新赋值，写 `PG.M = null`（ES 模块不允许直接给导入的变量赋值）；
  - 页面跳转函数（`home`、`codex`、`startQuiz`……）一律写成 `PG.xxx()`，返回键靠它记录走过的页面；
  - 每个模块顶部用 `reg({...})` 把自己的名字登记进去；浏览器控制台里 `PG` 可以直接访问所有模块，方便调试。
- **新增文件**：在 `src/main.js` 里按依赖顺序加一行 `import "./xxx/yyy.js";`。
- **新增一首歌**：在 `music/scores/` 新建乐谱文件，在 `music/tracks.js` 的曲目表里加一项，按需加入 `FEATURED`（精选）和 `TRACK_GROUPS`（分组）；
  英文名写进 `i18n/ui.js`。
- **导入歌曲（不改代码）**：设置 → 背景音乐 → 「＋ 导入歌曲（JSON）」，格式说明和示例就在面板里；导入的歌存在 `pg_songs`，进完整备份。代码在 `music/usersongs.js`（解析、乐器表）和 `pages/songs.js`（面板）。
- **改题库内容**：只动 `src/data/` 里的数据文件，按文件开头的格式说明改。英文版对照在 `i18n/data.js`。
- **题库扩展包（不改代码，给同学用）**：选择考试范围 →「＋ 题库扩展包」，或设置 →「管理题库扩展包」。扩展包是一个 JSON（格式说明和示例在面板里），
  导入后成为新的一章，组编号从 1001 起、药物编号从 10001 起，和内置数据不会撞。存在 `pg_packs`，进完整备份；删除时连同它的学习记录一起清掉。
  也可以在 AI 出题页 ④ 让 AI 根据讲义生成，并入后标「AI·未审核」，核对后再标为已审核。
  代码：`data/packs.js`（解析、存储、启动时并进题库，必须排在 `data/index.js` 前面）、`pages/packs.js`（面板）、`ai/packgen.js`（AI 生成）。
  扩展包里的药可能缺某些字段，出题器遇到空字段会跳过那一种题型，不会出空选项。
  首页有「题库扩展包」大板块；可视化编辑器在 `pages/packedit.js`（新建、改预览、改已并入的包：原来的药保留编号和学习记录，删掉的药清记录，草稿存 `pg_packDraft`）。
  组里至少 3 种药、2 种以上写了区分要点时，会自动生成一个「同类辨析」类别（只有特点辨认题）。
- **AI 专题**分三页：入口 `aiHub`（两个板块）→ 生成 `aiGen`（`ai/hub.js`）/ AI 题库 `aiLibrary`（`ai/library.js`：题集卡片、搜索、批量选择移动）。下拉菜单用自绘的 `ui/popmenu.js`，不用系统原生 select。
  AI 自查在 `ai/review.js`：复核题目（结果存 `q.check`，题库里有“自查有问题”筛选）和扩展包（预览里逐条采纳建议），生成页可选“生成后自动自查”。
- **AI 出题**：② 可选题型（单选 / 多选 / 判断 / 混合）、题干风格、题量、难度、解析详略、出题范围（含错题本、扩展包、自选药物组）、挑药方式；③ 资料题可存入自己命名的「题集」（`set` 字段，空题集存在 `pg_aiSets`），AI 题库里可以按题集筛选、改名、移动、单独练。
- **连击分级**（`ui/combo.js`）：选择题是夸奖阶梯 + 连击条（第三档起“狂热”光晕），断连有碎裂提示；连线是光束 + 连对成串升级，每轮按失误给 1–3 星，零失误“完美清盘”。特效都挂在 body 上，不进 #main。
- **成就与收集**（`pages/achieve.js`）：30 个成就（铜 / 银 / 金），结算和回首页时检查，存 `pg_ach` / `pg_achCnt` / `pg_days`；药物组练过 10 题且掌握度 ≥80% 点亮闪卡。加成就就在 `ACH` 表里加一行。
- **界面文字**：中文直接写在代码里；英文要么用 `TT("中文", "English")`，要么在 `i18n/ui.js` 加对照。

## 测试

`npm test` 会：
1. 构建在线版和离线版；
2. **对照测试**：用固定的随机种子，把拆分前的离线版（`legacy/pharm-game-before-split/offline/`）和新版本逐页比较界面文字（中英文 × 在线版 / 离线版，各 30 个页面）；
3. **功能测试**：音乐（25 首曲子的渲染响度）、连线干扰项与“记不清”、返回键、选择题“记不清”、备份恢复、题库扩展包（导入 → 出题无空选项 → 删除），以及 iPad / 手机尺寸下的逐像素截图对比。

对照测试以拆分前的版本为基准。拆分后**有意新加**的界面文字登记在 `tests/parity.mjs` 的 `ADDED_OK` 里，比对时去掉；
截图测试在手机尺寸下不比对顶栏（拆分前的版本在 390px 手机上顶栏会把页面撑宽 25px，已修复），并会先去掉新加的入口（`#songImp`、`#pkSec`、`#pkHome`、`#fcTool`、`#fcQuick`）。以后再有意加新内容时，用 `SHOW_ADDED=1 node tests/parity.mjs zh dist` 看多出来哪些行，确认后加进 `ADDED_OK`。

## 发布

- **离线版**：`npm run build:desktop`，桌面上的 `药理闯关-离线版.html` 会更新，发到 iPad / 手机直接打开。
- **网页版**：https://qyrdyx.github.io/pharm-quest/ （GitHub Pages）。手机浏览器打开后“添加到主屏幕”，像 App 一样全屏打开，打开过一次以后没网也能用；安卓推荐用这个，不会出现切出去再回来“无法访问”的问题。由 `npm run build` 生成到 `dist/pages/`，从公开仓库的 gh-pages 分支发布。
- **意见反馈**：首页最下面的「意见反馈」会把意见、出错记录和错题整理好，用邮件发到作者邮箱（`src/pages/feedback.js` 里的 `FEEDBACK_EMAIL`）。
- **精简版**：桌面上的 `药理闯关-离线版-精简.html`，和离线版完全一样，只是没有摇滚医生（少了约 1.3 MB 的乐器录音）。想省空间就用精简版；想玩摇滚医生，换回完整的离线版就行。在电脑上用同一个浏览器打开时，两个文件共用同一份学习数据（换之前也可以先在设置里做一次数据备份）。
- **Windows 上当程序用**：桌面快捷方式「药理闯关（应用）」用 Edge 的应用模式打开桌面上的离线版（独立窗口、没有地址栏、任务栏单独图标）。
  每次 `npm run build:desktop` 后它打开的就是最新版。快捷方式的图标在 `assets/app.ico`，由 `node tools/make-icon.mjs` 生成。
- **在线版**：把 `dist/` 里的 `index.html`、`app.js`、`app.css` 发布出去。`dist/index.html` 是页面片段（claude.ai 发布时会自动套上 doctype / 字符集 / 视口外壳）；本地预览 `http://localhost:5181/dist/` 时，预览服务器也会照样套上。
- 以后打包成安卓 APK / 苹果 IPA：用 Capacitor 包装 `dist/`，见讨论记录。

## 版本管理（git）

项目文件夹 `D:\药理闯关` 就是一个本地 git 仓库（只在这台电脑上，没有上传到任何网站）。`node_modules`、`dist`、`dist-dev` 不进仓库，需要时重新构建即可。

| 想做的事 | 命令（在项目文件夹里运行） |
|---|---|
| 看改了哪些文件 | `git status` |
| 看历史版本 | `git log --oneline` |
| 把当前改动存成一个版本 | `git add -A` 然后 `git commit -m "这次改了什么"` |
| 某个文件改坏了，恢复到上次存的样子 | `git restore 文件路径` |
| 临时回到某个旧版本看看 | `git switch --detach 版本号`，看完 `git switch main` |

注意：`legacy/` 里拆分前的旧版本还带着已下架的曲目，仓库如果以后要公开，需要先处理这部分。
